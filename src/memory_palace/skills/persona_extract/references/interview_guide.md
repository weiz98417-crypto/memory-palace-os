# 访谈员操作手册

## 访谈前准备

### 确认清单
- [ ] 已通知受访者访谈时长约1小时
- [ ] 场地安静、不受打扰
- [ ] 已准备记录工具（录音需征得同意）
- [ ] 了解受访者岗位名称和工作年限

### 访谈目标
每次访谈应提取 **5-10条逻辑条目**，每条包含：
- `trigger`：触发条件（「当…时」）
- `behavior`：判断行为（「我会…」）
- `reason`：背后原因（「因为…」）

## 五大问题使用指南

### 问题1：情境判断（必须）
从4个类别中选择2-3个，覆盖人员安全、设施故障、天气异常、客诉冲突。
**目标：3-5条逻辑条目**

### 问题2：升级信号（必须）
挖掘升级决策的边界信号，以及"不需要升级"的情况（anti-patterns）。
**目标：2-3条逻辑条目 + 2-3个anti-patterns**

### 问题3：错误经验（核心）
这是最有价值的部分。新人容易在这里卡住不知道怎么问。
**技巧**：
- 不要问"你犯过什么错"，这样问会让人防御
- 改成"有没有哪次处理完你觉得不太满意"
- 或者"新人和老手最大的差别是什么"
  **目标：1-3个错误案例，每个都要有正确做法**

### 问题4：反直觉处理（可选）
需要受访者对业务有较深理解，新人可能说不出反直觉的处理方式。
**目标：1-3个反直觉案例**

### 问题5：总结（必须）
访谈收尾，提取核心理念。
**目标：1句话总结 + 1-2条额外逻辑条目**

## 追问技巧

### 什么时候追问
1. 员工说"大概"、"可能"时 → 要求具体
2. 回答太笼统时 → "能举个具体例子吗？"
3. 出现专业术语时 → "这个词是什么意思？当时什么情况？"
4. 逻辑链条不完整时 → "为什么你会这么判断？是什么让你这么想？"

### 追问话术
- "能举个例子吗？当时具体发生了什么？"
- "这种情况一般多久处理完？"
- "有没有例外的情况？"
- "你后来是怎么知道当时判断对不对的？"
- "有没有同事做法和你不一样？结果怎么样？"

## 注意事项

### 避免事项
- ❌ 不要打断受访者，让他说完整
- ❌ 不要表现出认同或反对（保持中立）
- ❌ 不要用自己的经历回应（变成你在说）
- ❌ 不要问引导性问题（"你应该会这么做对吧？"）

### 特殊情况处理
- 受访者紧张 → 先聊几句家常，等放松再开始
- 受访者说不出来 → 换个场景或类别
- 受访者跑题 → 温和拉回："您刚才说的XX很有意思，能再展开说说吗？"
- 录音时 → 每15分钟确认一次受访者状态

---

## 萃取质量自检

访谈结束后快速检查：
- [ ] 每个问题都有实质性回答（不是"没什么特别的"）
- [ ] 至少有1个错误经验条目
- [ ] 逻辑条目都有 trigger + behavior + reason 三个字段
- [ ] 没有真实姓名（只有岗位名称）
