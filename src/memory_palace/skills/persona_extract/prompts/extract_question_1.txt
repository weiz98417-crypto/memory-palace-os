### 问题1：情境判断（核心萃取问题）

请从以下类别中选择2-3个，逐一询问：

**类别A：人员安全类**
"假设现在有游客在景区突然晕倒或受伤，你第一反应是什么？会先做什么判断，再做什么动作？"

**类别B：设施故障类**
"遇到设备突然坏了（比如缆车停止、扶梯故障），你怎么判断要不要停运整个区域？"

**类别C：天气异常类**
"遇到突然下大雨或者起雾，你能见度变差的时候，你会怎么决定要不要关闭部分区域？"

**类别D：客诉冲突类**
"遇到情绪激动要投诉的游客，你是怎么判断他是真的需要帮助，还是只是发泄情绪？"

---

### 每次追问技巧
得到回答后，顺着追问：
- "这种情况一般多久会处理完？"（了解处置周期）
- "有没有遇到过判断失误的情况？"（挖掘错误经验）
- "当时是什么信号让你这么做？"（提取判断依据）

### LLM 解析要求
从员工回答中提取以下格式的逻辑条目（可能多个）：
```json
[
  {
    "trigger": "当……时（例如：当游客突然晕倒时）",
    "behavior": "我会……（例如：立即通知医疗组，同时记录现场情况）",
    "reason": "因为……（例如：因为晕倒可能是心脏问题，不能随意移动）"
  }
]
```

### 输出格式
```json
{
  "question_id": 1,
  "question_type": "情境判断",
  "raw_answer": "员工原始回答（保留）",
  "logic_entries": [
    {"trigger": "...", "behavior": "...", "reason": "..."}
  ],
  "follow_up_needed": true/false,
  "follow_up_topic": "追问方向（如果需要）"
}
```
