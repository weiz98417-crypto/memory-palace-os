# 企业演示版权限与访问边界

## 当前角色

| 角色 | 允许操作 | 限制 |
|---|---|---|
| 本机演示人员 | 查看场景、运行控制、下载报告、Reset | 仅适用于 `127.0.0.1` 本机环境 |
| Demo Adapter | 生成确定性工具证据 | 不持有真实渠道密钥，不执行外呼 |
| 应用容器用户 `appuser` | 读取应用代码，写入 `/app/data` 卷 | 非 root，无 Docker 控制权限 |
| 企业连接管理员 | 在生产化阶段配置外部服务 | 不属于 V1 默认演示流程 |

## 资源操作矩阵

| 资源 | 读取 | 修改 | 删除/重置 | 当前保护 |
|---|---|---|---|---|
| 场景定义 | 本机浏览器 | 不允许通过 API 修改 | 不允许 | 镜像内版本化 YAML |
| 场景运行 | 本机浏览器 | Play/Pause/Step/Stop | 当前 run Reset | 状态机 + `expected_version` |
| 报告 | 有 run_id 的本机浏览器 | 不允许 | 不允许 | 本机绑定；V1 无用户级鉴权 |
| Demo 数据卷 | 应用容器 | 应用数据写入 | `demo.cmd reset` | 独立 Compose 项目和卷名 |
| 真实通知渠道 | 不配置 | 不允许 | 不适用 | Demo Adapter 硬隔离 |

Demo 模式采用路由白名单，只挂载企业场景 API、`/demo` 控制台和 `/health`。旧 `/api/v1/*`、`/api/v2/*`、`/webhook/*`、`/demo/send`、`/admin`、`/docs` 与 `/openapi.json` 均不挂载。

## 明确缺口

- Demo API 没有用户身份、组织、租户或 RBAC；不能公网部署。
- SQLite 没有行级安全；当前隔离来自单机、单演示环境和独立卷。
- 生产化必须在 API 前增加身份认证、资源级授权、审计主体和速率限制验证。
