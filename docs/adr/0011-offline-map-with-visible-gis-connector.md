# ADR-0011: 离线作业地图与可见 GIS 连接器并存

## 状态

已接受

## 决策

第一版使用离线 SVG/Canvas 景区作业地图作为默认地图 Adapter，同时在系统治理和地图详情中展示 GIS/在线地图连接器的接口信息、当前状态、数据契约和未配置原因。GIS 连接器不参与默认演示关键路径。

## 原因

本机演示需要稳定、离线和可复现；讲解时又需要说明未来如何接入真实 GIS、地图瓦片、坐标和设备点位。将连接器状态可见化可以诚实展示“当前已验证”和“可选连接”的区别。

## 影响

- 地图 interface 必须独立于 SVG/Canvas、在线瓦片和真实 GIS Adapter。
- 页面显示当前 Adapter、坐标系、数据更新时间、接口能力和配置状态。
- 未配置 GIS 时必须显示 `OPTIONAL_CONNECTION / NOT_CONFIGURED`，不能显示为实时在线。
- 接入真实 GIS 时只替换地图 Adapter，不修改态势和事件模型。
