# ADR-0010: bge-m3 采用 CPU 可运行、GPU 可选加速

## 状态

已接受

## 决策

景区模拟环境必须支持 Windows 本机 CPU 运行 `bge-m3`，GPU 作为可选加速路径。模型下载到本机持久化目录，容器或本地进程只读加载；启动检查报告模型、设备和可用内存状态。

## 原因

演示电脑不应依赖特定显卡或 CUDA 环境。CPU 路径保证可交付性，GPU 路径改善批量索引和实时检索延迟。

## 影响

- 首次索引和实时检索必须有可见的处理中状态与耗时。
- 不以“GPU 不可用”判定系统不可用。
- 模型下载和缓存不放入 Git 或应用镜像层。
- CPU 路径必须显式约束 OpenMP/MKL 线程数（`EMBEDDING_CPU_THREADS`，默认 4，进程启动前生效）。本机验证发现 torch CPU 运行库在默认满线程（6）下做 embedding 前向计算会以原生访问冲突中止进程，限制线程预算后稳定产出 1024 维向量；该约束由 `LocalEmbeddingBackend` 固化，不由部署脚本临时设置。
