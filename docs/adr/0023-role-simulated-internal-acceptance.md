# ADR-0023：角色模拟验收与证据驱动的就绪判定

状态：已接受（2026-09-22，项目负责人在审查会话中确认）。

内部验收由自动化执行者使用不同角色的正式账号完成，覆盖事件上报、有依据建议、人工角色决策、任务与审批、闭环、经验治理、第二名员工复用，以及 App 重启恢复。采用角色模拟替代重复人工点击，以获得可重复验证的完整业务证据；认证、授权、业务状态、模型、检索、队列和审计仍走真实系统，业务状态只能通过正式接口推进。

注册表依据本次运行的逐项证据更新：内部业务、平台和八个 Agent 全部通过对应门禁后标记 READY，DeepSeek 另须真实调用成功。生产企业微信继续 DISABLED_BY_POLICY；短信、语音未具备供应商验收证据时继续 DISABLED_REQUIRES_CONFIG，安全禁用验证可以通过其相关旅程。故障旅程以正确拒绝、恢复、去重和可追溯性判定通过。

这项决定允许完成内部验收而无需真人逐步点击，不替代客户签收、目标环境持续运行、供应商沙箱验收或产品负责人视觉签收。一次主旅程成功也不自动证明全部功能就绪；须补齐注册表各项要求和四入口功能、视觉及回滚证据。

执行范围、工作包和证据合同见 [审查修复与角色模拟验收计划](../product/review-remediation-and-role-uat-plan.md)。
