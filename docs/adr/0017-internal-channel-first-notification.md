# ADR-0017: 第一版以内部系统接入环境承载通知

## 状态

已接受

## 决策

景区模拟环境第一版的通知主路径是内部系统接入环境：通知写入可审计 outbox，由接入环境展示、接单和回执。短信和语音保留可替换 Adapter、审批和状态呈现，但不初始化生产供应商，也不宣称已完成外部送达。

## 原因

内部渠道可以在本机完成可见的通知、接单和回执闭环，同时保持生产外部渠道的诚实状态。这样不需要为了演示引入真实手机号、供应商密钥或不可控的外呼副作用。

## 影响

- 事件处置必须能关联 outbox、收件人、送达、接单和回执证据。
- 业务页面使用“已送达内部系统接入环境”等准确状态。
- 系统治理页面显示短信、语音和其他外部渠道的配置状态与 Adapter 信息。
