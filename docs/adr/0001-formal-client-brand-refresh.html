Architecture Decision Record · 0001

正式客户端品牌升级

记忆宫殿 · Memory Palace OS

已接受 · 2026-07-29

Decision

正式客户端将升级为面向值班/运营负责人的冷静指挥台：先呈现下一步处置，再呈现数据与组织记忆。

范围登录页与运营工作台
不包含Demo、营销页、大屏
工作树codex/frontend-brand-system
认证仅真实服务端认证

What We Decided

品牌成为工作秩序的一部分，而非装饰层

以 #0D0F1A 与 #1A1F3C 建立低对比信息表面，以 #5B6EFF 承担主操作，紫色仅承担品牌与 AI 提示。风险状态始终使用独立语义色。

Boundaries

本期交付边界

正式客户端

统一产品名为“记忆宫殿 · Memory Palace OS”，覆盖登录、导航、浏览器标题与系统通知。

真实认证

移除硬编码 admin / 123456、本地假登录和伪安全承诺。只展示服务端实际支持的账号密码或 SSO 入口。

响应式行为

交付 1440px 桌面和 390px 移动端。移动端优先登录、事件查看与待办确认，不压缩完整治理控制台。

Information Architecture

从技术功能导航转为业务工作流

指挥中心

活跃事件、SLA 风险、待确认事项与最新 Agent 证据。

事件处置

评估、分派、行动、回执、证据与闭环。

任务与审批

需要人工归属、确认或业务决定的工作。

组织记忆

案例、SOP 与专家经验形成的可用资产。

系统治理

可靠性、集成、权限与审计证据。

Brand Behavior

动效与角色的使用规则

品牌开场

3 秒动效仅在首次进入登录页时静音、可跳过地播放一次；其他高频场景使用静态 LOGO。

记忆核心守护者

仅用于欢迎、空状态、经验萃取完成与 AI 建议区，作为低压场景的引导角色。

风险场景

不在 P0 告警、审批、失败或认证流程中使用角色图或品牌动效，避免削弱风险信号。

视觉噪音

不把紫蓝渐变铺满卡片和按钮；神经节点与穹顶线条只作低对比背景纹理。

Delivery

壳层先行，页面渐进迁移

01

基础层

整理 LOGO、色彩、字体、间距与组件状态；保持 FastAPI 静态托管，使用原生 ES Modules 和独立 CSS。

02

安全入口

完成登录界面、真实认证适配、加载与错误状态；认证接口未就绪时明确告知，不伪造成功。

03

处置优先

重构应用壳层与指挥中心，随后依次迁移事件处置、任务与审批、组织记忆、系统治理。

04

验收

在真实 API 下验证桌面/移动端、键盘可达性、减少动态效果偏好与错误状态，再进入合并评审。
