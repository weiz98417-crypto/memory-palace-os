# ADR-0004: 景区模拟采用可复现剧本与人工注入双轨输入

## 状态

已接受

## 决策

景区模拟环境同时支持版本化、可复现的事件剧本和授权的人工注入事件。两种输入都必须经过同一景区态势与事件入口，进入真实事件处置、任务、审批和审计流程。

## 原因

剧本保证演示和回归测试可重放；人工注入让演示人员能够根据现场讲解临时触发事件。纯随机数据无法稳定验证业务结果，单纯固定剧本又不能证明系统可交互。

## 影响

- 输入来源必须记录为 `REPLAY_SCENARIO` 或 `MANUAL_INJECTION`。
- 人工注入必须经过角色权限、区域范围和事件字段校验。
- 两种输入不能绕过正式事件入口或直接写入前端状态。
- 同一个输入必须遵守消息幂等和事件去重规则。
