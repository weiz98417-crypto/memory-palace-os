# ADR-0006: 第一条景区垂直演示故事

## 状态

已接受

## 决策

第一条完整垂直切片采用“雨后观光车异常 → 东门客流上升”故事：气象信号开启雨后复检窗口，12 号观光车产生设备异常，员工上报并附图，系统生成 P1 运营事件，检索 SOP、派发检修任务、经过经理审批停运并启用备用车辆，随后东门客流告警触发分流任务，最后完成现场回执、风险解除和复盘。

## 原因

这条故事同时覆盖设备、天气、客流三类监测信号，以及事件分级、任务、审批、现场回执、共享态势和复盘。它能在一条可讲解的故事中验证 A/B/C，而不是先做互不相关的页面。

## 影响

- 第一版设备、天气、客流 Adapter 以此故事的输入和时间线为验收基准。
- 其他事件类型先复用同一事件与态势接口，不提前扩展更多业务故事。
- 该故事必须支持剧本回放和人工在关键节点注入同等事件。
