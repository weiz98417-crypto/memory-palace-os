# ADR-0016: 使用预置业务账号进行多角色演示

## 状态

已接受

## 决策

本地景区模拟环境预置真实业务账号、角色、场地绑定和权限。演示人员通过不同浏览器会话登录值班经理、现场员工、设备检修员和知识负责人账号；产品界面不提供角色切换器，也不接受客户端提交任意用户或场地身份。

运行准备入口使用独立的受保护运维身份。

## 原因

多角色共享状态必须经过真实鉴权和权限检查。页面内切换角色会绕过登录、身份映射和租户边界，无法证明系统具备真实运营约束。

## 影响

- 演示脚本需要准备账号、凭据和浏览器会话。
- 角色切换本身成为可审计登录行为。
- 现场端、指挥中心和管理端只能显示当前账号有权查看的业务数据。
