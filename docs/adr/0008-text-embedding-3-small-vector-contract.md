# ADR-0008: 使用 text-embedding-3-small 生成向量

## 状态

已被 ADR-0009 取代

## 决策

向量知识索引使用 `text-embedding-3-small`，第一阶段固定默认 1536 维。模型名称、维度、提供方和模型版本写入每条向量记录；模型或维度变化时创建新索引版本，不覆盖旧向量。

## 原因

该模型与项目现有配置一致，质量和成本适合知识与经验检索。固定维度可以让 pgvector 表结构和索引稳定，也能在迁移和 UAT 中验证检索来源。

## 影响

- 应用必须使用兼容 OpenAI Embeddings 协议的 endpoint，并明确密钥来源。
- Embedding 服务不可用时必须返回“向量检索不可用”，禁止写入零向量或伪造命中。
- 历史向量若来自其他后端或模型，必须用当前 embedding 模型重新生成，不能假设旧向量维度或语义兼容。
