# ADR-0015: 将模拟输入控制隔离到受保护的运行准备入口

## 状态

已接受

## 决策

景区指挥中心、员工现场端和企业内部系统接入环境不显示“演示控制”、剧本播放器或模拟输入按钮。模拟时钟、剧本回放和人工信号注入通过受保护的运行准备入口或后台脚本执行，仅产生监测信号，不直接修改运营事件结果。

本地演示的产品表述为“本机运行的景区运营系统环境，外部设备接入层使用本地模拟数据”；不声明不存在的客户现场部署。

## 原因

把控制器放在业务界面会破坏指挥中心的真实性，也会让观众误以为事件结果可以被演示按钮直接伪造。隔离输入准备和业务处置能同时保留可重复演示与真实业务状态。

## 影响

- 运行准备入口需要独立权限、审计和本地访问限制。
- 业务界面只能看到信号来源和运行模式的合规状态，不显示播放器控件。
- 所有模拟输入仍必须经过正式态势与事件入口。
