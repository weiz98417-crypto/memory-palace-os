# ADR-0003: 景区模拟使用可控模拟时钟

## 状态

已接受

## 决策

景区模拟环境使用独立的可控模拟时钟，支持播放、暂停、单步和倍速。业务事件、设备读数、告警和态势快照使用模拟时间；审计、请求和系统运行记录同时保存真实墙上时间。

## 原因

演示需要在几分钟内复现跨时段的客流、天气和设备变化，也需要稳定重放同一事件。直接使用电脑墙上时间会让演示不可控，纯播放器时间又无法与真实业务审计区分。

## 影响

- 所有模拟输入必须带模拟时间戳和来源序号。
- 事件处置的 SLA 计算默认使用模拟时间，并在界面明确标识。
- 审计证据必须同时保留模拟时间和真实写入时间。
- 暂停模拟时钟不能撤销已经产生的业务状态或审计记录。
