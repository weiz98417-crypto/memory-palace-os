# ADR-0014: 景区指挥中心作为主演示入口

## 状态

已接受

## 决策

`/admin/` 的景区指挥中心作为景区模拟环境的主演示入口。`/assistant/` 承担员工现场端，`/simulator/wecom/` 承担企业内部系统接入环境，旧 `/demo/` 仅保留兼容和回归用途。

## 原因

值班/运营负责人需要先看到景区态势和下一步处置，再进入事件详情或切换到现场端。将主故事从指挥中心开始，能把地图、告警、事件、任务、审批和审计放进一条可讲解动线。

## 影响

- 指挥中心必须能从零开始启动和观察第一条垂直故事。
- 现场端和接入环境通过共享态势订阅显示同一运营事件。
- 旧 Demo 播放器不能成为新业务状态源。
