# ADR-0013: 使用 SSE 推送景区态势

## 状态

已接受

## 决策

景区态势使用 SSE 作为默认服务端推送通道，HTTP 负责控制动作，短轮询作为降级路径。订阅协议提供有序事件序号、当前模拟时间、快照恢复和断线重连语义。

## 原因

当前实时需求主要是服务端向多个页面推送态势和事件变化，而不是浏览器与服务端的高频双向通信。SSE 的连接模型更简单，足以提供肉眼无差异的实时感，并保留断线恢复能力。

## 影响

- 指挥中心、现场端和管理端共享同一个态势订阅 interface。
- 控制动作不通过 SSE 发送，仍走正式 HTTP 接口和权限校验。
- 现有只使用短轮询的 Demo 页面不作为新态势订阅实现；需要更新正式模拟入口。
- 需要在 nginx、FastAPI 和浏览器客户端验证长连接、缓存关闭和重连行为。
