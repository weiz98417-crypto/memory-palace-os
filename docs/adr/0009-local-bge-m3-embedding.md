# ADR-0009: 景区模拟使用本地 bge-m3 embedding

## 状态

已接受

## 决策

景区模拟环境使用本地 `bge-m3` 生成向量，固定 1024 维，并通过 PostgreSQL pgvector 检索。模型文件随本机运行环境准备，不依赖外部 embedding API。

正式环境可以增加远程 embedding Adapter，但必须使用独立的索引版本和兼容维度，不能覆盖模拟环境的 1024 维索引。

## 原因

本地模拟需要可离线、可重复运行。项目现有 embedding client 已按 `bge-m3` 的 1024 维设计；采用本地模型也避免景区演示被外部 API、密钥或网络波动阻断。

## 影响

- Docker 镜像或模型缓存需要包含约 2.2–2.3 GB 的模型文件，或在首次启动时完成受控下载。
- 启动检查必须明确显示模型是否已就绪，未就绪时禁止发布向量或伪造检索结果。
- pgvector 索引固定为 1024 维，模型升级必须新建索引版本并重新生成向量。
- 之前的 `text-embedding-3-small` 决策不再适用。
