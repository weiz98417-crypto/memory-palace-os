# ADR-0002: 本地景区模拟环境的真实性边界

## 状态

已接受

## 决策

景区模拟环境整合到正式 MVP 的业务链路中。事件、任务、审批、知识、审计和多角色页面使用真实业务状态与持久化流程；摄像头、客流、天气、设备、定位以及外部通知使用本地模拟 Adapter。

旧 `ScenarioController` 演示播放器保留兼容性，但不作为主演示入口，也不作为正式业务状态源。

## 原因

用户需要在本机演示完整的景区应急管理和实时监控交互，同时不能依赖真实景区设备或生产渠道。将模拟限制在外部输入与外部动作，能保持本地可重复运行，又能让事件处置、任务协同、审批、复盘和组织记忆经过真实业务链路。

## 影响

- 新的模拟输入必须通过正式事件入口进入系统，不能由前端直接改写业务状态。
- 所有模拟动作必须显示为模拟状态，不能伪装成真实设备或生产渠道结果。
- 后续真实设备接入应替换 Adapter，不应重写事件处置工作流。
- 主演示需要一个共享的景区态势与事件状态源，供指挥中心、现场端和管理端投影。
